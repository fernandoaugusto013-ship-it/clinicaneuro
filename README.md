# Neuro Imagem Arcoverde — site

Site estático (HTML + CSS + JS puro) da clínica Neuro Imagem, de Arcoverde e Pesqueira (PE).

- `index.html`: página principal
- `privacidade.html`, `medicina-do-trabalho.html`, `404.html`: páginas internas
- `js/config.js`: **número de WhatsApp e lista de convênios** (edite só aqui)
- `DESIGN.md`: direção visual e tokens
- `PENDENCIAS-E-REVISAO.md`: o que a clínica precisa enviar e a revisão final

Os dados que faltam aparecem no site como etiquetas amarelas **[PREENCHER]** e **[CONFIRMAR]**.

Para testar localmente: `python3 -m http.server` nesta pasta e abra http://localhost:8000.
